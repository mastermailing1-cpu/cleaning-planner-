# Gablevio Cleaning Planner — Read-Only Demo

This repository hosts a **sample-data-only, read-only preview** of the Gablevio Cleaning Planner.

Explore these six sections:
- Dashboard
- Rooms
- Reset Studio
- Routines
- Cleaning Log
- What's Included

All original controls remain visible. Navigation and preview filters can be explored. Editing, adding rooms or tasks, recording cleaning completions, saving, and running a focus timer require the full product. Restricted controls show a **read-only preview** notice at the top of the page. This demo does not use browser localStorage or save any data.

## Deploy to Vercel
1. Go to https://vercel.com/new.
2. Import the GitHub repository `mastermailing1-cpu/cleaning-planner-`.
3. Use **Other** as the framework, leave the build command empty, and deploy.

The downloadable Blank and Sample editions are **not** included in this public repository.
